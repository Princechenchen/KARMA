# Wingweight case (surrogate-quality facet)

The aircraft wing-weight engineering function: two continuous outputs and expert/physics knowledge (three standard box-type regions + a constraint-threshold band).

## Reproducing the finalized archive

1. `main_compare_wingweight_ext6_par.m` — KARMA and the core baselines (ten seeds, parallel pool).
2. `main_compare_wingweight_pibo_sub10.m` — the two piBO arms on the evaluated ten seeds; merge them into the archive with `add_pibo_to_wingweight_final10.m`.
3. `main_compare_wingweight_ext6_qbc.m` — the QBC arm.

Base builders: `make_wingweight_ext6_base.m`, `make_wingweight_subset10_base.m`. `main_Example_wingweight.m` shows the source evaluation.

- Finalized archive: `Wingweight_box3u_final10.mat` (core arms + piBO merge); candidate-pool base `ext6_ww_base.mat`.
- Convergence figures: `fig_wingweight_13m_paper_*.png`, regenerated by `../paper_output/plot_wingweight_13m_paper.py`.

Dependencies: the shared library folders at the repository root (numeric_sample/, src/, sampling_Funciton/, testFunc/, grid/, MRSM_subprograms1/, MS-PSO-pro/, third_party/GPML); the driver adds them to the MATLAB path itself.
